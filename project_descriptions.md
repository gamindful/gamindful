# Project Portfolio (https://github.com/gamindful and other resources)

**MusiKloud** — Music recommendation system built on CLAP audio embeddings and mel-spectrograms, with a FAISS vector index for similarity search, UMAP-based embedding visualization, and a FastAPI backend.

**GNN** — Graph neural network project applying GNNs to EEG functional-connectivity data from an open meditation/mind-wandering EEG dataset (OpenNeuro ds001787), backed by an evidence-based methodology report on EEG network analysis.

**TherapIA** — Local, fully offline emotion and speaker logger: records video and audio simultaneously, detects facial emotion and landmarks, and performs speaker diarization with per-speaker emotion recognition.

**de_pipeline** — PySpark ETL pipeline that ingests, transforms, and loads World Bank economic-indicator data into Parquet, with generated pipeline diagrams and a results dashboard.

**Mex_finance** — Interactive historical choropleth map of Mexico's economy, coloring each state and municipality by monthly top export product or dominant economic sector using live DataMéxico/INEGI data, with a local Python server that logs every data point viewed.

**fx-flights-tracker** — FastAPI service that tracks currency exchange rates and flight prices of interest, combining web scraping, scheduled background jobs, and time-series forecasting.
